1) Push:   double-click push.bat   (Windows)   or   ./push.sh   (Git Bash / Linux)
2) GitHub -> Actions -> wait for the green check. The build FAILS on purpose if the jar has no BedFightPlugin.class.
3) Download the artifact BedFight-jdk8 (or jdk17), unzip it -> BedFight-1.3.0.jar
4) Quick check before uploading to the server: open the jar with 7-Zip/WinRAR.
   You must see  plugin.yml  and  com/example/bedfight/BedFightPlugin.class
5) Stop the server, DELETE the old BedFight-1.3.0.jar from plugins/, put the new one in, start the server.
Local build: mvn -B clean package  ->  target/BedFight-1.3.0.jar
